# Verse

Verse — приложение для macOS и Windows для работы с артистами: парсинг Instagram, рассылки в директ, iMessage, Discord, Email и Spotify, общая CRM и встроенный ассистент.

## Скачать

Актуальная версия всегда на странице **[последнего релиза](https://github.com/Friderluvsu/instagramdmbot/releases/latest)**. Выберите файл под свой компьютер:

| Система | Файл |
|---|---|
| macOS, Apple Silicon (M1–M4) | `Verse-<версия>-arm64.dmg` |
| macOS, Intel | `Verse-<версия>-x64.dmg` |
| Windows 10 / 11 | `Verse-Setup-<версия>.exe` |

Новые версии приложение предлагает установить само.

## Установка на macOS

1. Откройте `.dmg` и перетащите **Verse** в папку «Программы».
2. Если при запуске macOS пишет, что приложение повреждено, откройте «Терминал» и выполните:

   ```bash
   sudo xattr -cr /Applications/Verse.app
   ```

   Введите пароль от Mac (символы не отображаются) и запустите Verse снова.

## Установка на Windows

Запустите `Verse-Setup-<версия>.exe`. Если появится окно SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае».

## Начало работы

1. Введите лицензионный ключ при первом запуске.
2. Добавьте аккаунты во вкладке «Аккаунты».
3. Откройте «Центр обучения» (значок шапочки вверху): там пошаговые сценарии по каждому разделу.
